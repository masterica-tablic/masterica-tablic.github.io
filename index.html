Макросы

У каждого есть код и файл, где макрос уже вставлен и к нему нарисована кнопка. Если не хотите возиться с редактором, скачивайте файл и работайте в нём.

Макрос меняет данные, и его нельзя отменить кнопкой "Назад". Сохраните копию файла перед первым запуском. Это относится к любому макросу, не только к моим.

Как вставить макрос

Пять минут один раз. Дальше макрос живёт в файле и запускается кнопкой.

Куда вставлять код

WPS Office · JavaScript

WPS Office

  1. Вкладка Инструменты → Макросы → Редактор Visual Basic. В WPS это редактор JavaScript, несмотря на название.
  2. Слева выберите ThisWorkbook или создайте модуль.
  3. Вставьте код целиком и сохраните файл.
  4. Запуск: Инструменты → Макросы → выберите имя → Выполнить.
Microsoft Excel · VBA

Microsoft Excel

  1. Нажмите Alt + F11.
  2. Insert → Module. Именно модуль, не лист: это разные вещи.
  3. Вставьте код в белое поле справа.
  4. Сохраните книгу как .xlsm, иначе макрос пропадёт при закрытии.
  5. Запуск: Alt + F8 → выберите имя → Выполнить.
Google Таблицы · Apps Script

Google Таблицы

  1. Меню Расширения → Apps Script.
  2. Удалите пустую заготовку myFunction и вставьте код.
  3. Сохраните (значок дискеты) и дайте проекту название.
  4. Обновите вкладку с таблицей: в меню появится пункт Макросы.
  5. При первом запуске Google попросит разрешение. Это нормально: вы разрешаете доступ собственному скрипту.

Кнопка вместо меню

Запускать через меню каждый раз неудобно. Проще один раз положить кнопку на лист.

Excel
  1. Вкладка Разработчик. Если её не видно: Файл → Параметры → Настроить ленту → поставьте галочку Разработчик.
  2. Вставить → Кнопка, нарисуйте её на листе.
  3. Excel сам предложит выбрать макрос, выберите нужный.
  4. Правой кнопкой по кнопке → Изменить текст.
WPS
  1. Вставьте любую фигуру: Вставка → Фигуры → прямоугольник со скруглением.
  2. Впишите в неё название, например "Убрать пустые строки".
  3. Правой кнопкой по фигуре → Назначить макрос.
  4. Выберите макрос из списка.
Google
  1. Ничего рисовать не нужно: функция onOpen в моём коде сама добавляет меню Макросы вверху таблицы.
  2. Если вставляете несколько моих макросов в один проект, оставьте один onOpen и допишите в него остальные пункты через .addItem.
  3. Меню появляется после обновления вкладки, не сразу.

Если что-то пошло не так

Это те ошибки, на которые я натыкалась сама. Они выглядят страшно, а чинятся в одно действие.

WPS пишет: "Назначение выражений, инициализация переменных и вызовы функций не допускаются за пределами функций"
В редакторе WPS на верхнем уровне разрешены только объявления функций. Любая строка вне function это ошибка. В моём коде этого нет: если ошибка появилась, значит, скопировался лишний кусок.
Excel: "Compile error: Syntax error" сразу после вставки
Чаще всего в начало попала строка Attribute VB_Name = "…". Она нужна при импорте файла, а при вставке текста её надо удалить.
Excel: "Duplicate declaration in current scope"
Где-то две переменные с именами, которые отличаются только регистром: names и nameS. Для VBA это одно и то же имя. Переименуйте одну.
Excel: "Only comments may appear after End Sub"
Строка Const или Dim стоит между процедурами. Все такие объявления переносятся в самое начало модуля.
Код почему-то оказался в "Лист1" вместо модуля
Редактор прыгает в тот модуль, где нашёл ошибку, и легко вставить код не туда. Проверьте дерево слева, удалите лишние копии: два одинаковых макроса в книге тоже дают ошибку.
После макроса Excel будто завис: не перерисовывает экран
Excel не завис, в нём осталась выключена отрисовка. Почти каждый макрос гасит её ради скорости строкой Application.ScreenUpdating = False и включает обратно в конце. Если макрос упал посередине, до включения дело не дошло. Лечится запуском любого макроса со строкой Application.ScreenUpdating = True или перезапуском Excel. В моих макросах возврат стоит так, что срабатывает и при ошибке.
Google пишет: "Приложение не проверено"
Обычное дело для своего же скрипта: Google не проверял именно ваш проект. Нажмите Дополнительные настройки → Перейти к проекту (небезопасно). Если текста нет, значит разрешение уже выдано.
В Google Таблицах не появилось меню "Макросы"
Меню создаёт функция onOpen, а она срабатывает только при открытии. Обновите вкладку с таблицей.
Макрос не запускается при открытии файла
Так и должно быть. Office блокирует макросы в файлах, скачанных из интернета. Правой кнопкой по файлу → Свойства → внизу галочка Разблокировать → ОК, потом открыть заново.
