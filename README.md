# Мастерская таблиц

Сайт: макросы для Excel, WPS Office и Google Таблиц плюс готовые таблицы.

## Что где лежит

| Файл | Что это |
|------|---------|
| `index.html` | главная страница сайта |
| `repetitor.html` | страница таблицы "Учёт учеников и оплат" |
| `files/` | файлы, которые скачивают посетители |
| `.nojekyll` | служебный, нужен GitHub Pages, не удалять |

## Как поменять текст на сайте

1. Откройте сайт, добавив в конец адреса `#edit`:
   `https://ВАШ-АДРЕС/#edit`
2. Справа внизу появится кнопка "Изменить". Правьте текст, добавляйте карточки.
3. Нажмите "Скачать обновлённый index.html".
4. Здесь, на GitHub: "Add file" - "Upload files", перетащите скачанный
   `index.html`. Он заменит старый, сайт обновится через минуту.

Без `#edit` кнопки редактирования не видно, посетители её не найдут.

## Как добавить новый файл для скачивания

1. Зайдите в папку `files`, нажмите "Add file" - "Upload files".
2. Загрузите файл. Имя латиницей, без пробелов, например `otchet-2026.xlsx`.
3. Откройте сайт с `#edit`, в разделе "Ссылки" впишите путь:
   `files/otchet-2026.xlsx`
4. Сохраните и загрузите новый `index.html`.
